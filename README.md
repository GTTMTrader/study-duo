# 우리의 공부 (Study Duo) — 설치 가이드

갤럭시 · 윈도우(데탑/노트북) · 아이폰에서 같은 데이터를 실시간으로 보는 2인 스터디 앱.

- **앱 화면**: 이 폴더 전체를 GitHub Pages에 올려서 씀 (웹앱 = PWA)
- **데이터 저장/동기화**: Firebase (구글의 무료 서버)
- 비용: **0원** (Spark 무료 플랜, 카드 등록 없음)

> Firebase 연결 전에도 GitHub Pages에 올리면 **데모 모드**로 화면은 볼 수 있어.
> 주소 끝에 `?sample=1` 붙이면 시연 데이터가 나옴.

## 1. Firebase 프로젝트 만들기

1. PC 크롬으로 **https://console.firebase.google.com** 접속 → 구글 계정으로 로그인
2. **프로젝트 만들기**(또는 "Firebase 프로젝트 시작하기") 클릭
3. 프로젝트 이름: `study-duo` (아무거나 OK) → 계속
4. **Google 애널리틱스: 끄기** (필요 없음) → 프로젝트 만들기
5. 1분 기다리면 "새 프로젝트가 준비되었습니다" → 계속

## 2. 웹 앱 등록 → config.js 채우기

1. 프로젝트 첫 화면 가운데 **`</>` 아이콘(웹)** 클릭
   - 안 보이면: 왼쪽 위 톱니바퀴 ⚙ → **프로젝트 설정** → 아래 "내 앱" → `</>`
2. 앱 닉네임: `study-duo-web` → **"Firebase 호스팅도 설정" 체크하지 말기** → 앱 등록
3. 이런 코드가 나옴 👇 여기서 `firebaseConfig = { ... }` 안의 값만 필요해

   ```js
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "study-duo-xxxx.firebaseapp.com",
     projectId: "study-duo-xxxx",
     storageBucket: "study-duo-xxxx.appspot.com",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef..."
   };
   ```
4. 이 폴더의 **`js/config.js`** 를 메모장(또는 VS Code)으로 열어서 빈 칸 `''` 6개에 그대로 복사해 넣고 저장
5. 콘솔로 돌아가서 "콘솔로 이동"

> 🔒 apiKey가 GitHub에 공개돼도 괜찮아. 이건 "어느 프로젝트인지" 알려주는 주소 같은 거고,
> 실제 보안은 4단계의 **보안 규칙**(등록된 이메일 2개만 접근 가능)이 담당해.

## 3. 로그인 켜고 계정 2개 만들기

1. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**
2. "로그인 방법" 탭 → **이메일/비밀번호** 클릭 → 첫 번째 스위치 **사용 설정** → 저장
   (두 번째 "이메일 링크"는 끄기 그대로)
3. 위쪽 **Users** 탭 → **사용자 추가**
   - 내 이메일 + 비밀번호(6자 이상) → 사용자 추가
   - 한 번 더: 친구 이메일 + 비밀번호
   - 진짜로 쓰는 이메일 아니어도 됨 (예: `bully@study.com`). 인증 메일 안 감.
4. 친구한테 이메일/비밀번호 알려주기

## 4. 데이터베이스(Firestore) 만들기 + 보안 규칙

1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
2. 위치: **`asia-northeast3 (Seoul)`** 선택 ← 한 번 정하면 못 바꿈 → 다음
3. **프로덕션 모드에서 시작** 선택 → 만들기
4. 만들어지면 위쪽 **규칙** 탭 클릭
5. 안에 있는 내용 **전부 지우고**, 이 폴더의 **`firestore.rules`** 파일 내용을 통째로 붙여넣기
6. 붙여넣은 내용 중 이 줄을 **3단계에서 만든 이메일 2개**로 바꾸기 (전부 소문자):
   ```
   request.auth.token.email in ['me@example.com', 'friend@example.com'];
   ```
7. **게시** 클릭

> 이게 끝나면 Firebase 쪽은 완료. 데이터 구조(방, 기록 등)는 앱이 처음 로그인할 때 알아서 만들어.

## 5. GitHub Pages에 올리기

1. github.com 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름: `study-duo` → **Public** → Create repository
3. "uploading an existing file" 클릭 → **이 폴더 안의 파일·폴더 전부** 끌어다 놓기
   (`index.html`, `styles.css`, `sw.js`, `manifest.webmanifest`, `firestore.rules`, `README.md`, `js/` 폴더, `icons/` 폴더)
   → Commit changes
4. 저장소 **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
5. 1~2분 뒤 주소 생김: **`https://gttmtrader.github.io/study-duo/`**

> ⚠ `js/config.js`를 채우기 **전에** 올렸으면, 채운 뒤 그 파일만 다시 업로드하면 돼.

## 6. 기기별 설치

### 갤럭시 (나)
1. **크롬**으로 `https://gttmtrader.github.io/study-duo/` 열기
2. 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 "앱 설치") → 설치
3. 홈 화면 아이콘으로 실행 → 로그인

### 윈도우 데탑 + 노트북 (친구) — 두 대 다 똑같이
1. **엣지** 또는 **크롬**으로 같은 주소 열기
2. 주소창 오른쪽 **앱 설치 아이콘(⊕ 모니터 모양)** 클릭 → 설치
   - 엣지: ⋯ → 앱 → "이 사이트를 앱으로 설치"
3. 별도 창으로 뜸 → 작업 표시줄에 고정 → 로그인 (두 대 모두 **같은 친구 계정**)
4. 창 크기는 세로로 길게 줄여서 써도 됨

### 아이폰 (선택)
1. **사파리**로 같은 주소 열기 (크롬 X)
2. 아래 공유 버튼 □↑ → **홈 화면에 추가** → 추가
3. 홈 화면 아이콘으로 실행 → **여기서 다시 로그인** (사파리랑 로그인이 따로 저장됨)

## 7. 테스트 체크리스트 (갤럭시 + 친구 PC 동시에)

- [ ] 둘 다 로그인됨, 설정(⚙)에서 각자 **이름** 저장 → 상대 화면에 이름 뜸
- [ ] 갤럭시에서 타이머 시작 → 친구 PC 홈에 "공부 중" 표시
- [ ] 갤럭시 화면 끄고 2분 뒤 켜기 → 시간 정확히 흘러 있음
- [ ] 1분 넘기고 종료 → 양쪽 홈 "이번 주 대결"·"오늘" 숫자 바뀜
- [ ] 친구가 **데탑에서 시작 → 노트북에서 종료** 가능
- [ ] 진도 체크 → 상대 화면에 코랄/블루 체크 표시
- [ ] 기록 탭에서 내 기록 × 눌러 삭제 → 양쪽에서 사라짐

## 앱 사용 메모

- **D-day / 주차**: 한국 시간 기준으로 매일 자동 계산. 2026-11-02(월) 시작 → 9주(매주 1챕터) → 2027-01-04부터 "최종 복습 기간" → 01-09 "오늘 시험"
- **주간 대결**: 달력 기준 월~일 합계 (커리큘럼 주차와 별개)
- **진행 중 타이머 포함**: 홈·기록 숫자에 지금 돌아가는 타이머 시간도 실시간으로 들어감
- **타이머 깜빡**: 4시간 넘게 켜져 있다가 종료하면 실제 공부한 분을 고칠 수 있게 물어봄
- **1분 미만**: 저장 안 됨
- **기록은 시작한 날짜**로 들어감 (밤 11시 시작 → 새벽 1시 종료면 시작한 날)
- **화면 켜두기**: 타이머에서 켜면 공부 중에 폰 화면이 안 꺼짐 (배터리 주의)
- **오프라인**: 인터넷 끊겨도 타이머·체크 됨 → 연결되면 자동 업로드

### 챕터·단원 입력 (설정 ⚙)

지금은 1~4장 이름, 2장 탄수화물 단원 7개만 들어 있어. 개념서 목차 보고 이렇게 채우면 돼:

```
01 | 소화와 흡수 | p.1–33
- 소화기관의 구조
- 소화 과정

02 | 탄수화물 | p.34–73
- 탄수화물의 종류
...
```

- `번호 | 챕터명 | 페이지` 한 줄, 그 아래 `- 단원명`
- 챕터 9개 = 9주. 개수를 바꾸면 주차 수도 따라 바뀜
- 체크는 "몇 번째 단원"으로 기억하니까, **체크 시작한 뒤에는 중간에 단원 끼워 넣지 말기**
- 시험일·시작일·챕터는 **둘이 공유** (한 명이 고치면 둘 다 바뀜)

## 문제 해결

| 증상 | 해결 |
|---|---|
| 로그인: "이메일 또는 비밀번호가 틀렸어요" | 3단계 Users 탭에 계정 있는지 확인. 비번 잊으면 거기서 ⋮ → 비밀번호 재설정 |
| "권한이 없어요" 토스트 | 4단계 규칙의 이메일 오타/대문자 확인 → 게시 다시 |
| 계속 "데모 모드" 배너가 뜸 | `js/config.js`에 apiKey가 비어 있음 → 채워서 다시 업로드 |
| 고친 게 앱에 반영 안 됨 | 앱 완전히 껐다 켜기 (2번). 그래도 안 되면 `sw.js`의 `VERSION` 숫자 올려서 다시 업로드 |
| "데이터 연결 중…"에서 멈춤 | 4단계 Firestore 데이터베이스를 안 만든 것 |

## 무료 한도 (넉넉함)

Firestore 무료: 하루 읽기 5만 / 쓰기 2만 / 저장 1GB.
둘이 하루 종일 써도 읽기 몇백~몇천 수준이라 걱정 없음.

## 파일 구조

```
index.html            앱 뼈대
styles.css            디자인 (시안 색상 그대로)
js/config.js          ★ Firebase 설정값 넣는 곳
js/app.js             화면 4개 + 계산
js/dates.js           D-day, 주차, KST 날짜 계산
js/defaults.js        기본 시험일·커리큘럼·챕터
js/store-firebase.js  Firebase 저장/동기화
js/store-demo.js      데모 모드 (설정 전 미리보기)
sw.js                 오프라인 캐시
manifest.webmanifest  홈 화면 앱 설정
firestore.rules       ★ Firebase 보안 규칙 (콘솔에 붙여넣기)
icons/                앱 아이콘
```
